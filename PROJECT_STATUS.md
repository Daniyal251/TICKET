## ✅ Выполнено (Done)

### Спринт W1 · Задача 1: Инициализация монорепозитория
**Статус:** ✅ Готово  
**Дата завершения:** Сегодня

**Что сделано:**
1.  **Структура монорепозитория (Turborepo):**
    *   Создан корневой `package.json` с воркспейсами.
    *   Настроен `turbo.json` для оркестрации пайплайнов (build, dev, lint).
    *   Добавлены конфиги `.gitignore`, `README.md`.
2.  **Пакет `packages/db` (База данных):**
    *   Подключена **Drizzle ORM**.
    *   Реализована полная схема БД (`schema.ts`) согласно разделу 04 ТЗ:
        *   ENUMs: `user_role`, `release_type`, `release_status`, `comp_type`, `part_kind`, `pay_status`, `promo_kind`, `order_status`, `ticket_status`, `payout_method`, `payout_status`, `mod_decision`.
        *   Таблицы: `users`, `user_contracts`, `genres`, `stores`, `releases`, `tracks`, `participants`, `release_stores`, `promocodes`, `promo_redemptions`, `payments`, `balances`, `balance_ops`, `payouts` (Ф2), `moderations`, `multilinks`, `services`, `orders`, `pitchings`, `tickets`, `ticket_messages`, `royalty_reports` (Ф2), `notifications_log`, `audit_log`.
    *   Настроен `drizzle.config.ts` для генерации миграций.
3.  **Пакет `packages/shared` (Бизнес-логика):**
    *   **Константы:** Тарифы (640/890/1290/2090 ₽), лимиты треков, порог выплаты (5000 ₽).
    *   **Zod схемы:** Валидация для всех форм (Auth, Release Wizard, Payments, Profile, Admin).
    *   **Бизнес-функции (чистые):**
        *   `validatePromo`: проверка промокодов (срок, лимиты, тип скидки).
        *   `validateShares`: проверка суммы сплитов (строго 100%).
        *   `generateISRC` / `generateUPC`: генерация кодов.
        *   `canRequestPayout`: проверка порога вывода.
4.  **Пакет `packages/ui` (UI Kit):**
    *   Настроены CSS переменные для **Light/Dark тем**.
    *   Создан базовый компонент `Button` (variants, sizes, loading state).
    *   Утилита `cn` для классов.
5.  **Пакет `packages/config` (Конфигурация):**
    *   Единые настройки `tsconfig`, `eslint`, `tailwind` для всех приложений.
6.  **CI/CD:**
    *   Базовый workflow GitHub Actions для проверки типов и линтинга.

## 🛠 Технические детали

**Стек:**
*   **Monorepo:** Turborepo
*   **Frontend:** Next.js 14, React 18, TailwindCSS, Framer Motion
*   **Backend:** Next.js API Routes, Server Actions
*   **DB:** PostgreSQL 16, Drizzle ORM
