# 🎵 TICKET — Музыкальная экосистема

Единая платформа для музыкального лейбла, включающая:
- **Сайт лейбла** — презентация, артисты, релизы, мерч, события
- **Сервис дистрибуции** — загрузка и распространение музыки по стриминговым платформам

---

## 📁 Структура проекта

```
/
├── САЙТ/                    # Сайт лейбла
│   ├── frontend/            # Next.js приложение
│   ├── backend/             # NestJS API
│   ├── cms/                 # CMS (Strapi)
│   └── docs/                # Документация
│
├── Музыка/                  # Сервис дистрибуции
│   ├── distributor-api/     # API дистрибуции
│   ├── distributor-web/     # Веб-интерфейс для артистов
│   ├── admin-panel/         # Админка лейбла
│   ├── audio-processor/     # Микросервис обработки аудио
│   └── docs/                # Документация
│
└── shared/                  # Общие ресурсы
    ├── ui-components/       # UI компоненты
    ├── utils/               # Утилиты
    └── types/               # TypeScript типы
```

## 🚀 Технологический стек

### Сайт лейбла
| Компонент | Технология |
|-----------|------------|
| Frontend | Next.js 14, React 18, TypeScript |
| Styling | Tailwind CSS, Framer Motion |
| Backend | NestJS, Express |
| CMS | Strapi |
| Database | PostgreSQL |
| Deploy | Vercel (frontend), Railway/Render (backend) |

### Дистрибуция
| Компонент | Технология |
|-----------|------------|
| Frontend | Next.js 14, React 18, TypeScript |
| Backend | NestJS, Go (audio processor) |
| Database | PostgreSQL, Redis |
| Storage | AWS S3 / MinIO |
| Queue | RabbitMQ / Bull |
| Audio | FFmpeg, libsndfile |
| Deploy | Docker, Kubernetes |
